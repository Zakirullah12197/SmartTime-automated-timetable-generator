# 🌌 COLOR SYSTEM — “Deep Slate Intelligence”

Create a sophisticated productivity-focused color system.

## 🌑 DARK MODE (PRIMARY EXPERIENCE)

### Core Backgrounds

* App Background → `#080A0F`
* Surface Layer 1 → `#11141D`
* Surface Layer 2 → `#151A24`
* Elevated Glass Surface → `rgba(255,255,255,0.04)`

### Accent Palette

* Electric Indigo → `#6366F1`
* Aurora Violet → `#A855F7`
* Intelligent Emerald → `#10B981`

### Typography Colors

* Primary Text → `#F8FAFC`
* Secondary Text → `#CBD5E1`
* Muted Text → `#94A3B8`

### Border System

* Thin subtle dividers only
* `rgba(255,255,255,0.08)`

No harsh separators.

---

## ☀️ LIGHT MODE (SECONDARY EXPERIENCE)

### Backgrounds

* Main → `#F8FAFC`
* Surface → `#FFFFFF`
* Secondary Surface → `#EEF2FF`

### Typography

* Primary → `#0F172A`
* Secondary → `#334155`
* Muted → `#64748B`

### Shadows

* Soft diffused shadows only
* Extremely subtle depth

Avoid heavy dark shadows.
